# CreateNeedsMD
C.N.M.D. 的表面英文全稱提案： Create Needs MarkDown (你原本的提案)  風格： 最務實。我有需求（Needs），幫我生出 Markdown（MD）。  Copy N' MarkDown  風格： 強調動作的「極致無腦」。用戶只需要 Copy（複製貼上），然後拿走 Markdown。N' 是 And 的口語縮寫。  Can't Navigate My Day  風格： 厭世感點滿。「我今天已經無法運作/無法面對這一天了」，所以只好把一切交給 AI。  Complete Nonsense, Make Done  風格： 翻譯過來就是「一堆狗屁倒灶的事，快幫我搞定」。非常符合把爛攤子丟給 AI 處理的心態。
